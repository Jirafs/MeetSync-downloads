## Установка


1. Откройте нужный релиз, затем раздел **Assets** и скачайте файл с расширением **.apk**. Архивы **Source code** не устанавливают приложение.
2. Откройте APK на телефоне. При запросе Android разрешите установку из выбранного браузера или файлового менеджера. Минимальная версия — Android 8.0.
3. Запустите MeetSync. Адрес интернет-сервера уже встроен; компьютер разработчика держать включённым не нужно.
4. Создайте аккаунт по email, подтвердите почту по ссылке в письме и нажмите «Я подтвердил почту» в приложении. Локальные аккаунты старой версии автоматически не переносятся.


## Статус беты


Это тестовые сборки для обратной связи, не стабильная версия. Перед установкой читайте ограничения конкретного релиза и проверяйте SHA256 скачанного файла.


Бесплатный сервер засыпает без запросов. Первое обращение может занимать около минуты; фоновые действия и напоминания при остановленном сервере задерживаются. Push и встроенная карта пока не приняты. Каталог Москвы автоматически пополняется из Geoapify; доступны поиск, фильтры и избранное аккаунта. Полная проверка интерфейса на двух телефонах ещё не завершена.


Не отправляйте пароли, токены и ключи в Issues. Для ошибки укажите версию Android, версию MeetSync и шаги воспроизведения без личных данных.
